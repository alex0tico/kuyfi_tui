The problem

Most tools need your source code. Kuyfi doesn't.

Other tools

Source-code required

Formal verifiers like Veridise and Certora operate on the original Rust source. If you don't own the contract or lost the source, you're stuck. Human auditors face the same constraint — no source, no audit.

→

Kuyfi

Deployed bytecode only

Kuyfi fetches the WASM from the live contract on Testnet, decodes the contractspecv0 XDR custom section with an alignment-tolerant parser, reconstructs the function interface — and starts probing. No Rust. No repo.

Suggested workflow: Run Kuyfi → fix obvious issues → submit to Veridise or Ottersec with a cleaner baseline. Arrive at the audit having already eliminated surface-level vulnerabilities.
How it works

Two phases. One command.

01

OSINT Scanner

● Stable
  • Fetch WASM bytecode from any Testnet contract ID — read-only, zero transactions
  • Decode contractspecv0 XDR custom section with an alignment-tolerant parser
  • Build UDT struct registry from scSpecEntryUdtStructV0 entries
  • Render attack surface map: function names, typed parameters, return types
02

Chaos Monkey

● Beta / In Testing
  • Ephemeral keypair + Friendbot funding — keys never touch disk
  • Math boundary vectors, one variable at a time:
ZERO_ATTACK MAX_VALUE_ATTACK NEGATIVE_ATTACK MIN_BOUNDARY_ATTACK
  • Access control vectors on admin-pattern functions:
UNAUTHORIZED_CALL REINIT_ATTACK SELF_CALL_ATTACK
  • Full on-chain execution pipeline:
simulate → assemble → sign → submit → poll
  • Terminal report with severities CRITICAL / HIGH / MEDIUM / LOW / INFO and sequential finding IDs (KYF-001, KYF-002…)

03 · Planned

PDF & JSON audit reports · CI/CD pipeline integration · Multi-contract batch scanning · Monitoring dashboard · kuyfi.io SaaS platform

Why Stellar · Why now

The first production smart contract platform on Stellar needs a security-first toolchain.

[WASM]

Soroban is WASM-native

Every deployed Soroban contract is a WASM binary on-chain, with its interface encoded in the contractspecv0 custom section. Kuyfi reads exactly that — no source needed.

[GAP]

The audit gap

Veridise, Ottersec, and CoinFabrik deliver rigorous human audits — but they require source code and significant budget. Kuyfi is the automated, CLI-native triage layer that runs before formal review.

[NOW]

Early-ecosystem window

Soroban DeFi protocols are deploying now. The tooling for black-box inspection of deployed contracts didn't exist before Kuyfi. This is the right time to build the security baseline.

[CLI]

Profile it like a closed binary

Kuyfi brings the black-box mindset of binary security research to Soroban: fetch, decode, map, fuzz — all from the deployed artifact, the way an attacker would approach it.

Kuyfi runs entirely on Stellar Testnet and is built with the official @stellar/stellar-sdk.
